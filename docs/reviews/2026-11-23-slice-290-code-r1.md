## Verdikt

Der Code folgt dem Verfahren Schritt für Schritt. Die Ausnahmen kommen aus der geteilten Lexik, und
die Tests sind echt: 19 von 20 Mutationen werden rot, die Gegenprobe am Korpus trifft die
Plan-Zahlen genau. **F-1 blockiert**: Ein Schalter ohne Wert schaltet die Ausnahme still ein. Lastenheft und
Handbuch führen das als Exit 2, getragen wird es nur von der Plan-Notiz. Das ist dieselbe Klasse wie
F-1 in R2 zu `slice-289` (`plan-entscheid-hinter-lastenheft`), also das **zweite** Auftreten in
`welle-95`. Beim dritten ist der Konflikt-Pfad Pflicht (`v6.18.1` ·
`regelwerk/modul-08-agentenrollen.md` §Konflikt-Pfad als Rollen-Sequenz). Ein Rollen-Widerspruch
liegt hier noch nicht vor; die Lesart von „gesetzt“ entscheidet der Architect, danach zieht der
Implementer Code oder Handbuch nach. F-2 bis F-4 sind Wartungs- und Reichweiten-Punkte ohne heutige
Fehlwirkung, F-5 bis F-7 Hinweise.
