### F1 — INFO · Quelle: `DC-FA-CLI-010` Out-of-Scope · spec/spezifikation.md:330 / internal/adapter/driving/cli/print_mk.go:43

Der `else`-Zweig setzt `DCHECK_REF := ghcr.io/pt9912/d-check@$(DCHECK_DIGEST)`
mit **fest verdrahtetem** Repo-Pfad. Ein Konsument, der `DCHECK_IMAGE` auf eine
abweichende Registry/Pfad setzt **und** zugleich `DCHECK_DIGEST` angibt, erhält
`ghcr.io/pt9912/d-check@<digest>` — sein `DCHECK_IMAGE`-Registry-Override wird
verworfen. Die Prosa „sticht den Tag von `DCHECK_IMAGE`" suggeriert nur einen
Tausch des Tag-Anteils; `§…010.a` Punkt 3 zeigt jedoch die literale `…/d-check@`-Form,
womit das Verhalten in der Spezifikation explizit dokumentiert ist (kein verdeckter
Bruch). **verifizierbar:** ja — `make -n -f frag doc-check DCHECK_IMAGE=myreg/x:v DCHECK_DIGEST=sha256:abc`
expandiert zu `ghcr.io/pt9912/d-check@sha256:abc` (belegt).
