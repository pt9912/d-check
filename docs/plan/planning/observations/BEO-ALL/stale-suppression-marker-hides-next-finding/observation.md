# Ein Unterdrückungs-Marker, der nichts mehr unterdrückt, bleibt stehen und deckt lautlos den nächsten Befund

**Sub-Area:** `*`

Ein Marker wird gegen einen konkreten Befund gesetzt; verschwindet dieser,
bleibt der Marker und schweigt fortan über etwas, das niemand
stummschalten wollte. Für Go ist die Frage seit `nolintlint`
(`allow-unused: false`) gemessen; für den eigenen `d-check:ignore`-Marker
gibt es kein Gegenstück — gemessen: 233 Zeilen tragen die Zeichenkette
(Teilketten-Suche), nur 87 in Kommentar-Form, 146 sind bloße Prosa.
