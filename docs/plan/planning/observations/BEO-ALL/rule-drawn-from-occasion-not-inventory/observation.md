# Eine Aussage oder Regel wird aus dem Anlass gezogen statt aus dem Bestand

**Sub-Area:** `*`

Wer eine Eigenschaft am gerade bearbeiteten Fall beobachtet, erklärt sie für
exklusiv, allgemein oder abschließend — ohne die Nachbarn gezählt zu haben.
Drei Ausprägungen: (a) eine Exklusivitäts-Aussage („das einzige …"), (b) ein
Kriterium, das eine bereits korrigierte Menge nachträglich begründet, ohne
dass die Herleitung wirklich nur diese Menge trifft, und (c) eine Regel, die
nur für den Ort geschrieben wird, an dem sie wehtat, statt für ihre Klasse.
Kein Gate fängt eines davon — alle drei sind Prosa.
