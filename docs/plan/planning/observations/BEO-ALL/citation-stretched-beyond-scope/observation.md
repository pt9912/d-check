# Eine Quelle wird über ihren Geltungsbereich hinaus zitiert

**Sub-Area:** `*`

Der Text der Quelle stimmt, die in Anspruch genommene Reichweite nicht: ein
Satz, der im Kanon nur für einen benannten Fall gilt, wird als universale
Regel geführt; ein `MR-`Eintrag wird nach seinem Titel statt nach seinem
Feld `Geltungsbereich` zitiert; eine ADR-Entscheidung wird als stehendes
Verbot gelesen, obwohl sie einen einmaligen Akt beschreibt. Unterschied zu
[`BEO-ALL/rule-drawn-from-occasion-not-inventory`](../rule-drawn-from-occasion-not-inventory/observation.md):
dort wird eine Regel aus dem Anlass gebildet, hier wird eine bestehende
gedehnt — und weil ein Zitat wie ein Beleg aussieht, ist es schwerer zu
bemerken als eine unbelegte Behauptung.
