# Ein geplanter Testfall fährt die Regel nicht, die er belegen soll

**Sub-Area:** `*`

Ein Testfall im Plan nennt eine Regel als Begründung, lässt sich aber so bauen, dass er
auch ohne die Regel grün bliebe — die Eingabe erreicht den Zweig der Regel gar nicht.
Ableiter: zu jedem geplanten Testfall den Vorzustand ohne die Regel ausschreiben und
prüfen, ob er dann rot wäre.
