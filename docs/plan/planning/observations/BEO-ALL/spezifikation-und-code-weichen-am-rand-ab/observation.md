# Spezifikation und Code weichen an einem harmlosen Rand voneinander ab

**Sub-Area:** `*`

Die Spezifikation beschreibt einen Rand enger oder anders, als der Code ihn
behandelt, und weil der Rand selten getroffen wird, fällt es nicht auf — bis
ein neues Modul sich auf das bestehende beruft und die Abweichung übernimmt
oder ihr widerspricht.
