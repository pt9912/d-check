**Vorgang:** slice-289
**Fund:** Die Spezifikation von `metrics` ([`DC-FA-MET-001.a`](../../../../../../../spec/spezifikation.md#dc-fa-met-001a--kennzahl-eines-planungsdokuments-gegen-messung-aus-git-metrics)) nimmt ein `\r` nur unmittelbar vor `\n` aus; der Code schneidet es auch am Ende einer letzten Zeile ohne `\n` ab. Aufgefallen, als `linelength` sich für dieselbe Regel auf `pinsync` und `metrics` berief ([Review R2](../../../../../../../docs/reviews/2026-11-23-slice-289-review-r2.md) F-2); `linelength` beruft sich jetzt nur auf [`DC-FA-PSYNC-001.a`](../../../../../../../spec/spezifikation.md#dc-fa-psync-001a--gleichheit-eines-wertes-an-mehreren-stellen-pinsync). Die `metrics`-Spezifikation ist unverändert — außerhalb der Welle.
