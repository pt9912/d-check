# Ein Gate wird rot, und der Grund ist ein anderer als der geprüfte

**Sub-Area:** `*`

Der Nachweis „die Regel greift" stützt sich auf den Exit, nicht auf die
gelesene Ursache — ein roter Exit ist erstaunlich leicht aus dem falschen
Grund zu bekommen: falscher Linter in der Probe, eine nie gefahrene
Direktiv-Form, eine Probe im ausgenommenen Abschnitt. Die Gegenrichtung
gehört dazu: der unveränderte Bestand, auf dem der Sensor schweigen muss.
Kein Gate fängt das — ob ein roter Exit vom geprüften Grund kommt, ist ein
Urteil über eine Meldung, kein `grep`.
