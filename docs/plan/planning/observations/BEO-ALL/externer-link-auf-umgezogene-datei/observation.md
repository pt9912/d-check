# Ein Link von außen auf eine umgezogene Datei bricht ohne Signal

**Sub-Area:** `*`

Zieht eine Datei im Repo um, folgen alle Verweise im Repo — Verweise von
außen (Adopter, Blog, Issue) zeigen weiter auf den alten Pfad und brechen,
ohne dass ein Gate es sehen kann. Ableiter: einen Umzug einer Datei, auf die
von außen verlinkt wird, in der Release-Notiz nennen.
