# Gemessen wird die eigene Menge, ausgesagt wird über die fremde

**Sub-Area:** `*`

Die Frage war, ob sich ein gepinnter Fremd-Bestand bewegt; gezählt wurde,
wie oft **wir** den Pin je gehoben haben. Ein Bestand, den nur wir ändern,
kann über einen Bestand, den nur andere ändern, nichts sagen. Test vor
jeder Messung: wer ändert die Menge, die ich zähle — und wer ändert die,
über die ich rede? Verwandte Variante: dieselbe Verwechslung mit einer
**eigenen Teilmenge** statt einem fremden Bestand (gezählte Felder ⊊
tatsächlich gesuchte Menge). Verwandt, aber nicht dasselbe: [`BEO-ALL/rule-drawn-from-occasion-not-inventory`](../rule-drawn-from-occasion-not-inventory/observation.md)
zieht eine Aussage aus zu wenig Bestand — hier ist genug gezählt, aber das
Falsche.
