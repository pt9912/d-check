# Eine geteilte Lexik driftet an den Rändern, weil jeder Konsument sie selbst vorbereitet

**Sub-Area:** `*`

Nicht die Lexik selbst war das Problem, sondern dass mehrere Stellen
dieselbe Zeile verschieden trimmten und zwei Automaten dieselbe Frage
verschieden beantworteten. Jede Stelle für sich vertretbar — zusammen ein
stiller Grün-Pfad, den kein Gate sieht, weil jedes Modul für sich
konsistent ist.
