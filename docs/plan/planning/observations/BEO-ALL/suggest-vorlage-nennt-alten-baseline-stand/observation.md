# Die Vorlage von `--suggest-config ai-harness` nennt einen alten Baseline-Stand

**Sub-Area:** `*`

Die Harness-Vorlage ist an eine adoptierte Baseline-Version gebunden und nennt
sie im Kommentar-Kopf
([`DC-FA-CLI-006`](../../../../../../spec/lastenheft.md#dc-fa-cli-006--konfigurations-vorschlag-aus-autoritäts-dokumenten)).
Code und Spezifikation nennen dort weiter `v1.3.0`, während einzelne
Vorschläge — etwa `"8. Historie"` — der Vorlage eines späteren Stands folgen.
Kopf und Inhalt sagen damit verschiedene Stände. Ableiter: bei jedem
Vorschlag, der einer neueren Vorlage folgt, den Stand im Kopf mitprüfen.
