# Eine Commit-Botschaft behauptet mehr, als die Arbeit trägt

**Sub-Area:** `*`

Zwei Richtungen: (a) sie behauptet eine Probe oder Änderung, die nicht
stattfand — formuliert vor oder während der Arbeit, reist die Behauptung
trotz gescheiterter Probe mit; (b) sie verallgemeinert über die Messung
hinaus — die genannten Proben liefen und stimmen, aber der Schluss reicht
weiter als sie. Beleg-Form-Lücke dieses Eintrags: er trug schon bei Zähler 3
nur zwei Kennungen statt drei — nicht stillschweigend passend gemacht,
sondern hier benannt.
