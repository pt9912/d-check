# Eine Probe auf einen Wettlauf, die zweimal grün läuft, hat nichts widerlegt

**Sub-Area:** `*`

Bei einem zeitabhängigen Test wurde die vermutete Bedingung erzwungen statt
abgewartet; zwei grüne Läufe führten zum Schluss „die Deutung ist
widerlegt". Der dritte Lauf desselben unveränderten Codes schlug fehl — die
Deutung war richtig. Bei einem nichtdeterministischen Prüfling ist Grün
kein Ergebnis; nur Rot trägt eine Aussage.
