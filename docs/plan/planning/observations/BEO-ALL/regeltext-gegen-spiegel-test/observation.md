# Ein Regeltext erlaubt, was ein Spiegel-Test verbietet

**Sub-Area:** `*`

Eine Dokumentations-Regel sagt, ein Eintrag dürfe im Feature-Commit fehlen; ein
Spiegel-Test macht `make test` rot, solange er fehlt. Wer der Regel folgt,
bricht das Gate, und wer dem Gate folgt, handelt gegen den Wortlaut der Regel —
der Plan muss die Ausnahme jedes Mal neu begründen.
