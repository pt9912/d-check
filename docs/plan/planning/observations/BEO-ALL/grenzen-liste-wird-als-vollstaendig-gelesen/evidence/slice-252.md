**Vorgang:** slice-252
**Fund:** Viertes Auftreten in Folge am Modul `targets`. Lastenheft,
Spezifikation und ADR beschrieben die Disjunktheit als „steht als
Tabellenzeile in mehr als einer Datei"; der Code zählte jede Zelle, die
Baseline meint die führende — ein Werkzeug-Teil mit „eingehängt in
`make gates`" wäre gemeldet worden (R1-H1). Dass die Prüfung ohne
`targets.makefiles` gar nicht lief, stand nur im Code (R1-M1). Nach der
Behebung blieben fünf Spiegel auf der alten Lesart stehen (V3). Eine eigene
Black-Box-Probe vor dem Review bestätigte die Byte-Identität korrekt, fand
aber keinen dieser Fälle — sie prüfte die Fälle, an die der Autor dachte.
