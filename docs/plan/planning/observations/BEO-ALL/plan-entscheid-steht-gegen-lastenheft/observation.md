# Ein Entscheid oder eine Notiz im Plan steht gegen das Lastenheft

**Sub-Area:** `*`

Der Plan hält einen Entscheid oder eine Festlegung absoluter oder anders fest, als
das Lastenheft sie trägt — eine Plan-Änderungs-Notiz des Implementers, eine
Zusammenfassung des Planners. Weil der Plan näher am Code liegt als die Spec,
folgt der Code dem Plan, und die Abweichung von Rang 1 ist nur noch an einem
Review zu sehen, das beide nebeneinander liest.

Test beim Schreiben einer Plan-Festlegung: Welche Stelle des Lastenhefts trägt
sie? Gibt es keine, ist sie eine Entscheidung, keine Notiz.
