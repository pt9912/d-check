Lehre wie in slice-208, wo sechs Deklarations-Träger eine Abschnitts-**Nummer**
nannten. Behoben durch Benennung über den **Inhalt**. **(2)** Derselbe Plan
nannte
[`rule-drawn-from-occasion-not-inventory`](../../rule-drawn-from-occasion-not-inventory/observation.md)
