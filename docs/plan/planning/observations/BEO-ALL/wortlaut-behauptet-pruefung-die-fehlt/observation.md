# Ein Wächter, der nie fangen konnte, liest sich wie einer, der fängt

**Sub-Area:** `*`

Ein Test trägt in Name und Kommentar eine Zusage und misst sie nicht: die
Prüfung steht als Protokoll-Ausgabe statt als Assertion, oder die Fixture
erzeugt gar nicht den Zustand, über den der Name spricht. Beides ist grün
und von einem echten Wächter nicht zu unterscheiden — schlimmer als kein
Test, weil er die Lücke besetzt. Die Klasse ist nicht auf Tests beschränkt:
sie trifft jede Prüfung, deren Erfolgsfall der Normalzustand ist. Prozedur,
seit der ersten Instanz: wer einen Wächter für eine Zusage schreibt, dreht
sie einmal um und belegt, dass genau ein Test rot wird.
