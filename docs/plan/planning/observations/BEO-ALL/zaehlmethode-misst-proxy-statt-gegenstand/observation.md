# Eine Zählmethode misst einen Proxy, und aus ihren Artefakten wird eine Kategorie

**Sub-Area:** `*`

Eine Messung zählt nicht ihren Gegenstand, sondern ein Muster, das ihm
ähnelt — und weil sie eine plausible Zahl liefert, fällt das nicht auf.
Gefährlich wird sie erst im zweiten Schritt: Wer die **Treffer** ansieht und
sie für den Gegenstand hält, leitet aus den Fehltreffern eine Aussage ab, die
es nie gab. Unterschied zu
[`BEO-ALL/eigene-menge-gemessen-fremde-behauptet`](../eigene-menge-gemessen-fremde-behauptet/observation.md):
dort ist die gezählte **Menge** falsch und die Kategorie richtig; hier ist die Kategorie
erfunden. Ableiter: vor der Messung die **Form** des Gegenstands ausschreiben
(was macht eine Kennung zu einer Kennung?) und die Trefferliste stichprobenweise
gegen sie halten — nicht nur die Zahl.
